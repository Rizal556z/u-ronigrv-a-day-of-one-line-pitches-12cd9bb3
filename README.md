## What it does

`main.py` (Python 3, pure stdlib, no network) writes one sentence to
`/output/entry.txt` — a pitch that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun: just
describe the idea in plain words, no coding, no setup, no experience
needed.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is UTF-8, 167 Unicode code points, well within the 1–240 limit.
